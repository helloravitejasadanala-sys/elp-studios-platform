# Client gallery UX notes (public research)

Sources (marketing pages only, Oct 2026): Pixieset Client Gallery, Pic-Time Client Galleries, ShootProof Online Galleries.

## Patterns we aim for

1. **Cover first** — full-bleed or large hero with gallery title + date before the grid.
2. **Photography-first** — large images, minimal chrome, generous spacing, calm type.
3. **Effortless for families** — password once, favourites with one tap, clear download.
4. **Proofing** — favourites + optional comments; admin sees picks.
5. **Video with photos** — finished film in the same gallery (Katha).
6. **Mobile equal** — same flows on phone; no app required.
7. **Brand carry-through** — per-gallery logo/colours (placeholders until owner assets).

## Out of scope (deliberately)

Print shops, payments, CRM, beauty AI, microservices.
